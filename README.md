- 🤖 **Building AI agent workflows for real enterprise systems** — designed a multi-agent pipeline (GitHub Copilot agents + an MCP server + a code-knowledge DB) that speeds up modernizing a **1.3M-line, 3,100-feature** credit card platform to Spring Boot.
- ☁️ **Cloud-native microservices on AWS** — Spring Boot services on ECS with RabbitMQ, the outbox pattern, Cognito auth and CI/CD on GitHub Actions.
- 🦀 **Multi-tenant SaaS with Rust** — shared observability library and per-tenant authentication/authorization (Cognito, OpenFGA) for an AI retirement assistant.
- ⚡ **Performance-minded** — took a data-heavy batch job from **2 hours to 10 minutes** on millions of records.
